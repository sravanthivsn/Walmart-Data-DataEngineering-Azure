# Walmart Data Engineering Pipeline with dbt and Apache Airflow

## 📌 Project Overview

This project demonstrates an end-to-end data engineering workflow inspired by Walmart's retail data ecosystem. It integrates **Python, SQL, Apache Spark, dbt Core, and Apache Airflow** to build a modular, automated, and maintainable data pipeline. The goal is to transform raw retail data into clean, structured, and analytics-ready datasets for reporting and downstream analysis.

## 🎯 Project Objectives

- Build an automated ETL/ELT pipeline for retail data.
- Ingest and process data using Python, SQL, and Apache Spark.
- Transform raw data into analytics-ready datasets using dbt.
- Orchestrate and schedule workflows using Apache Airflow.
- Implement a layered data architecture with staging, intermediate, and data mart layers.
- Apply data quality checks and validation techniques.
- Manage code and configuration using Git and GitHub.
- Use Docker for reproducible development environments where configured.
- Incorporate CI/CD practices for testing and deployment.
- Prepare curated datasets for business intelligence and reporting.
